# Project Visibility Checklist

Track completion of project visibility and discoverability items.

## Package Metadata

- [x] PyPI package name is clear and searchable
- [x] Package description is concise and keyword-rich
- [x] Keywords cover main use cases (RAG, retrieval, ranking, visualization)
- [x] Classifiers are comprehensive and accurate
- [x] Author information is complete

## Repository

- [x] README has clear title and description
- [x] README includes badges (PyPI, Python versions, license)
- [x] README has installation instructions
- [x] README has quick start example
- [x] README links to documentation
- [x] LICENSE file present (MIT)
- [x] CHANGELOG maintained
- [ ] GitHub Topics configured
- [ ] Repository description set

## Documentation

- [x] MkDocs documentation configured
- [x] Getting started guide
- [x] Tutorial notebooks
- [x] API reference
- [ ] GitHub Pages enabled
- [ ] Documentation URL in pyproject.toml

## Social/Discovery

- [x] Blog post about the package
- [ ] Announced on social media
- [ ] Listed in awesome-* lists (if applicable)

## CI/CD

- [x] CI workflow for testing
- [x] Security scanning workflow
- [x] Documentation deployment workflow
- [x] Release workflow for PyPI

## Quality Signals

- [ ] Test coverage badge
- [ ] Code quality badge
- [ ] Downloads badge ✓ (in README)
- [ ] Active maintenance (recent commits)
