# Tutorials

Step-by-step guides to learn rankflow's features.

## Learning Path

1. **[Quickstart](01_quickstart.ipynb)** - Basic usage, creating your first rankflow plot
2. **[Metrics & Analysis](02_metrics_and_analysis.ipynb)** - Computing retrieval metrics (P@K, MRR, NDCG)
3. **[Advanced Visualization](03_advanced_visualization.ipynb)** - Customizing plots, highlighting, top-K filtering
4. **[Batch Evaluation](04_batch_evaluation.ipynb)** - Evaluating across multiple queries
5. **[Adapters & Export](05_adapters_and_export.ipynb)** - TREC/RAGAS formats, export to JSON/DataFrame

## Prerequisites

- Python 3.10+
- Basic familiarity with pandas and matplotlib
- Understanding of information retrieval concepts (optional but helpful)
